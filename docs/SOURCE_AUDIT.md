# Source audit

Checked 2026-10-03. Carried forward from Grid-Storage-Workshop and re-verified here.

## How the sources were verified

- Every upstream repository was re-cloned at its current `HEAD`. All ten `HEAD`s equal the commits pinned in `sources/upstream-lock.json`, so the vendored copies are the latest upstream.
- Every vendored file was byte-compared with the fresh clone. All matched, with three expected exceptions, each checked separately:
  - GridFlock's bundled Rebuilt library = the submodule pin `910e22d` (matched).
  - Rugged Box's bundled Rebuilt library = the older submodule pin `0b7bf6e` (fetched and matched). The two pins are not interchangeable.
  - HSW `custom-honeycomb-wall-v2.scad` = the original v2 recovered from commit `5e6ad4f` (fetched and matched).
- GridFlock's `paths/puzzle.scad` is generated by the upstream `extract_paths.py` from `puzzle.svg`; it is not in the upstream tree.
- `sources/SHA256SUMS` covers all 341 vendored files; `tools/validate_sources.py --hashes-only` passes.

## Reference-site inventory

`sources/reference-catalog.json` lists the 12 project families on gridfinity.perplexinglabs.com after removing GRIPS and GridPlates (superseded, by owner decision). The site disallows automated fetching of its metadata endpoints in robots.txt, so the inventory is the one captured on 2026-10-03 in the original repository; it was not re-scraped.

## Closing the gaps

These need the owner to supply the file or a source link; nothing here is guessed:

- **Anylid** and **openGrid Shelf** — download the SCAD from the MakerWorld pages (logged in) and add it with its license text.
- **Multiboard** — confirm which generator the site uses. Public candidates: [asciipip/multiboard-parametric-stacked](https://github.com/asciipip/multiboard-parametric-stacked), [slynn1324/mb-tile-generator](https://github.com/slynn1324/mb-tile-generator), and "Multiboard Parametric Extended" on Printables (882280).
- **openGrid Connector** — no upstream located. A related, actively maintained alternative is [mitufy/opengrid-projects](https://github.com/mitufy/opengrid-projects) (openConnect connectors, shelves, hooks, snaps); it could become its own family.

## Engine

This workspace cannot install OpenSCAD (package mirrors and openscad.org are blocked here), so rendering runs in GitHub Actions (`.github/workflows/validate.yml`) on an OpenSCAD development snapshot. Earlier results on OpenSCAD 2021.01 (original repo): 17 of 22 entrypoints compiled; Rebuilt Bin, Extended Bin/Baseplate, GridFlock and Basket need the newer engine. Production should pin one tested development snapshot with the Manifold backend.
